Hollow Duel is a Souls-like multiplayer boss fight built with Three.js and Firebase Realtime Database for authoritative state sync. Parry timing, stamina management, and a posture-break system drive the combat; the boss and its arena are procedurally varied by name and map seed each session. Everyone who joins with the same boss name fights the same fight together.
